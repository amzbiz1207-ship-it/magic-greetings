# Magic Greetings v0.3

Готовый комплект для размещения и проверки. Основа — предоставленный Magic Greetings v02 на Python / Streamlit / Pillow / FFmpeg.

## Что добавлено

Восемь самостоятельных праздничных фонов, 11 категорий, галерея с настоящими превью, независимые языки интерфейса и поздравления, три готовых поздравления на каждом из десяти языков, собственный текст и заголовок, имя, предпросмотр, настройка размера и положения фотографии внутри рамки, создание PNG / JPG и шестисекундного MP4. В видео снег и мерцание находятся по краям, текст плавно появляется.

Фотография целиком помещается внутри рамки. Можно уменьшать и перемещать её. Исходное изображение обрабатывается через Pillow без генеративной перерисовки, замены лица и ретуши. В PNG вставленные пиксели совпадают с результатом обычного масштабирования исходника. JPG и MP4 используют сжатие с потерями.

## Размещение в Streamlit Community Cloud

1. Создайте отдельный репозиторий GitHub для Magic Greetings.
2. Загрузите содержимое папки Magic_Greetings в корень репозитория. В корне должны быть app.py, engine.py, locales.json, templates.json, requirements.txt и packages.txt. Обязательно загрузите папку assets целиком.
3. В Streamlit Community Cloud создайте приложение из этого репозитория и выберите app.py.
4. Используйте Python 3.12. Секреты и API-ключи для генератора не требуются.
5. После запуска откройте сайт на компьютере и телефоне. Создайте открытку из своего фото, скачайте PNG/JPG и MP4, проверьте результат. Публичный адрес создаётся при размещении.

Папка examples содержит примеры. Её можно оставить в репозитории или убрать перед размещением. Для работы приложения она не требуется. verify.py использует эту папку при проверке.

## Локальный запуск

Требуются Python 3.12 и шрифты DejaVu Sans. Для Debian/Ubuntu установите fonts-dejavu-core. FFmpeg поставляется с imageio-ffmpeg.

    python -m pip install -r requirements.txt
    python -m streamlit run app.py

На Windows и macOS путь FONT_DIR в engine.py нужно изменить на папку установленных шрифтов DejaVu Sans. Готовая конфигурация предназначена для Linux-хостинга Streamlit.

## Проверка

    python verify.py

Результаты сохраняются в verification_results.json. Подробности и границы проверки приведены в TEST_REPORT.md.

## Файлы проекта

- app.py — интерфейс и состояние отдельного сеанса.
- engine.py — загрузка, проверка фото, композиция, экспорт.
- templates.json — области фото и текста, цвета, категории и локализованные названия.
- locales.json — интерфейс, сообщения и поздравления на десяти языках.
- assets — восемь фонов без поздравительных надписей и людей.
- examples — созданные этим генератором открытки и MP4.
- ARTWORK.md — происхождение изображений и описание промптов.

Чтобы добавить шаблон, положите фон в assets и добавьте запись в templates.json. Координаты задаются для открытки 1080 × 1350. Фото, заголовок и поздравление размещаются отдельно поверх фона.

## Фото и временные данные

Ограничения загрузки — 15 МБ, 20 мегапикселей, короткая сторона от 600 пикселей. Проверяются содержимое файла, освещение и резкость. Для портретных категорий проверяются наличие и число лиц. Семейная категория допускает несколько лиц. Категории питомцев и универсальных открыток не требуют человеческого лица.

Личные фото и результаты находятся в состоянии сеанса Streamlit и не записываются в папки проекта. Общий кэш используется только для фоновых изображений, шрифтов и демонстрационных превью. Видео создаётся в отдельной временной папке, которая удаляется после обработки. Кнопка очистки сбрасывает фото и результаты текущего сеанса. Фото проходит через сервер хостинга.

## Перед коммерческим запуском

Генератор подготовлен для размещения и пользовательской проверки. Оплата, учёт покупателей, выдача доступа, ограничение числа заказов и контроль нагрузки пока не подключены. Не размещайте платёжные секреты в репозитории.

Для подключения продаж нужно выбрать схему доступа. Простая ссылка после оплаты может быть передана другим людям. Для персонального доступа потребуются учёт покупателя и проверка оплаченного заказа на сервере. Платёжная интеграция будет отдельным этапом после проверки генератора на размещённом сайте.
